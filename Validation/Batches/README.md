# Catastrophe 游戏：20 个可执行验证 Batch

先关闭正在打开此项目的 Unity Editor，然后在本目录运行单个 Batch：

```bash
./run_batch.sh 01
```

运行全部验证：

```bash
./run_all.sh
```

每个脚本以 `0` 表示通过、`1` 表示验证失败、`3` 表示 Unity Editor 仍占用工程。日志写入 `Validation/BatchLogs/`。

## Batch 01–10：基础工程

1. 工程、LivingRoom 场景及 Build Settings
2. 小猫 Prefab、渲染器、Animator 与关键骨骼
3. Idle、Walk、Push Right、Jump 动画片段
4. 小猫控制器与基础物理组件
5. 扩大后的房间、新地板及墙体
6. 沙发、餐桌、椅子和桌面物件的独立层级与分区
7. 地板、桌椅、沙发材质与贴图资源
8. 地板与全部家具的 Collider
9. GameBootstrap、主摄像机和第三人称相机
10. 完整集成回归（依次执行 Batch 01–09 的全部断言）

## Batch 11–20：最终交付

11. 核心循环：破坏 → 得分 → 噪音
12. 四目标顺序与目标文案切换
13. 警报、三处躲藏点与一击失败
14. 胜利小票、失败面板、评级、最高分与跳转按钮
15. 开局稳定、推力参数、阻尼、速度钳制与出生保护
16. 撞击、碎裂、推、警报、躲藏、脚步和落地音效
17. 飘字、噪音条、播报与无毛黑白猫动画反馈
18. 独立可编辑的场景陈设与 Valuable 道具密度
19. 黄昏灯光、低机位防穿模、受限拖拽与滚轮缩放
20. 最终总回归（依次执行 Batch 01–19 的全部断言）

详细的缺口、实施内容和交付标准见 `FINAL_DELIVERY_BATCHES.md`。
